# ?? Guía Visual - Acceder a Swagger desde la Aplicación

## Método 1: Desde la Página de Documentación API (Recomendado)

### Pasos:

1. **Inicia la aplicación** 
   - Presiona `F5` en Visual Studio para ejecutar ambos proyectos
   - Espera a que se abran las ventanas del navegador

2. **Navega a la sección HERRAMIENTAS**
   - En la barra lateral izquierda, desplázate hacia abajo
   - Verás una sección llamada **HERRAMIENTAS**

3. **Haz clic en "Documentación API"**
   - Se abrirá una página con información sobre los endpoints
   - Verás una tabla con todos los endpoints principales
   - Haz clic en el botón azul "Abrir Swagger UI"

4. **¡Listo! Se abrirá Swagger en una nueva pestaña**

---

## Método 2: Botón Directo a Swagger

1. **En la barra lateral**, debajo de "Documentación API"
2. **Haz clic en "Swagger (Nueva Pestaña)"**
3. **Se abrirá el Swagger directamente en una nueva pestaña del navegador**

---

## Método 3: URL Directa en el Navegador

Si prefieres acceder directamente sin la interfaz gráfica:

```
https://localhost:7110/swagger/index.html
```

## ?? Usando Swagger

Una vez que abras Swagger, verás:

### 1. **Endpoints Disponibles**
   - Se agrupan por controlador (Pacientes, Citas, Laboratorio, etc.)
   - Cada uno con un color diferente para identificación

### 2. **Probando un Endpoint**
   - Haz clic en un endpoint para expandirlo
   - Haz clic en "Try it out"
   - Ingresa los parámetros necesarios (si aplica)
   - Haz clic en "Execute"
   - Ver la respuesta en tiempo real

### 3. **Ejemplo: Obtener todos los Pacientes**
   ```
   Endpoint: GET /api/pacientes
   1. Haz clic en el endpoint (verde)
   2. Haz clic en "Try it out"
   3. Haz clic en "Execute"
   4. Ver respuesta JSON abajo
   ```

### 4. **Ejemplo: Crear un Paciente**
   ```
   Endpoint: POST /api/pacientes
   1. Haz clic en el endpoint (azul)
   2. Haz clic en "Try it out"
   3. Completa el JSON en el área de "Request body"
   4. Haz clic en "Execute"
   5. Ver respuesta del servidor
   ```

## ?? Consejos Útiles

1. **Guardar ejemplos**: En Swagger puedes ver ejemplos de Request/Response
2. **Modelos**: Desplázate hacia abajo para ver los esquemas de datos
3. **Autenticación**: Si implementas JWT, podrás añadir el token en el botón "Authorize"
4. **Descargar especificación**: Haz clic en "Download" para obtener el archivo OpenAPI completo

---

## ?? Problemas Comunes

### "No se puede conectar a localhost:7110"
- Asegúrate de que el Backend API está ejecutándose
- Verifica en la ventana de consola que no hay errores
- Reinicia Visual Studio y ejecuta nuevamente

### "Error 404 - Swagger no encontrado"
- Verifica que Swagger esté configurado en `Program.cs`
- Asegúrate de usar la URL correcta: `https://localhost:7110/swagger/index.html`

### "CORS bloqueado"
- Esto ya está resuelto en la configuración actual
- Si aún tienes problemas, contacta al administrador
