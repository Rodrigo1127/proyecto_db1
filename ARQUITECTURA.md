## ?? Flujo de Datos

```
Usuario en Frontend
    ?
Hace clic en "Documentación API" o "Swagger (Nueva Pestaña)"
    ?
JavaScript Interop abre https://localhost:7110/swagger/index.html
    ?
Frontend muestra Swagger UI
    ?
Usuario selecciona un endpoint (ej: GET /api/pacientes)
    ?
Hace clic en "Try it out"
    ?
Completa parámetros (si los hay)
    ?
Haz clic en "Execute"
    ?
Swagger envía HTTP Request al Backend
    ?
Backend recibe la solicitud en el Controller apropiado
    ?
Controller llama al Service correspondiente
    ?
Service accede a la Base de Datos (DbContext)
    ?
Retorna los datos al Controller
    ?
Controller devuelve Response JSON
    ?
Swagger muestra el resultado en la UI
    ?
Usuario ve: Response Code, Headers, Body (JSON)
```
